# Project 5 – Network Automation & Deployment: Infrastructure Automation with Terraform, Ansible, & Python

## 5.7 Tools Used

Project 5 integrates Terraform, Ansible, Python, AWS cloud services, Linux operating systems, secure SSH administration, GitLab version control, and technical documentation tools to automate infrastructure deployment and validation.

![Project 5 — Tools Used](infographics/5.7%20Tools-Used.png)

Engineering Workflow: Provision → Configure → Validate → Document → Version Control.
