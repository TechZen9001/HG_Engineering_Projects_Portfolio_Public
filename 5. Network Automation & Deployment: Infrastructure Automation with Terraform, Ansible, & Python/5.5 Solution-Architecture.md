# Project 5 – Network Automation & Deployment: Infrastructure Automation with Terraform, Ansible, & Python

## 5.5 Solution Architecture Overview

Project 5 implements a centralized AWS cloud infrastructure automation architecture designed to provision, configure, secure, validate, and manage Linux-based cloud resources using Terraform, Ansible, Python, and Git/GitLab. The solution uses an Amazon Web Services (AWS) Virtual Private Cloud (VPC) containing two Amazon EC2 instances deployed into separate public subnets. The infrastructure includes an Ubuntu Linux instance for applications and tools and a Red Hat Enterprise Linux (RHEL) instance for management functions. A centralized developer workstation executes Terraform configurations, Ansible playbooks, and Python validation scripts to automate infrastructure provisioning, Linux system administration, network connectivity verification, and structured reporting. Git/GitLab provides version control, change tracking, and documentation management throughout the infrastructure automation lifecycle. The architecture demonstrates how Infrastructure as Code (IaC), automated configuration management, and programmatic validation can replace repetitive manual cloud administration with secure, standardized, scalable, and repeatable deployment workflows.

| 7  | SSH Authentication          | Test authorized SSH login using approved key-based authentication.             | Authenticated administrative connectivity confirmed.                                 |

Validation distinction: A successful TCP port 22 test confirms that a network connection can be established to the SSH service port. It does not independently prove successful SSH authentication, correct Linux permissions, or complete Ansible configuration. Those requirements must be verified separately.
