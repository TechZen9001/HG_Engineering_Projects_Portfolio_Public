# Project 5 – Network Automation & Deployment: Infrastructure Automation with Terraform, Ansible, & Python

## 5.3 Business Value

Project 5 demonstrates how cloud infrastructure automation can replace repetitive manual provisioning and configuration tasks with standardized, secure, scalable, and repeatable engineering workflows. By integrating Terraform, Ansible, Python, AWS, and GitLab, the solution illustrates opportunities to reduce infrastructure deployment costs, accelerate cloud service delivery, strengthen security, and improve operational efficiency.
