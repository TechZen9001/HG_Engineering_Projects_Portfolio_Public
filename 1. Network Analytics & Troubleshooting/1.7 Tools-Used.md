## 3. Cisco IOS CLI: Configuration & Troubleshooting

| Technical Capability     | Engineering Function                                                        | Example Command                | Key Benefit                                                |
| ------------------------ | --------------------------------------------------------------------------- | ------------------------------ | ---------------------------------------------------------- |
| Interface Verification   | Inspect interface status, IP addressing, and operational conditions.        | `show ip interface brief`      | Quickly verifies device interface status.                  |
| Routing Analysis         | Examine routing tables and available network paths.                         | `show ip route`                | Identifies routing and reachability problems.              |
| Connectivity Testing     | Test network communication to a destination.                                | `ping 10.10.10.1`              | Confirms basic IP connectivity.                            |
| Path Tracing             | Investigate the routed path toward a destination.                           | `traceroute 8.8.8.8`           | Helps identify routing paths and potential failure points. |
| VLAN Verification        | Inspect configured VLANs and associated access ports on supported switches. | `show vlan brief`              | Supports VLAN and segmentation troubleshooting.            |
| Trunk Verification       | Examine trunk status and VLAN forwarding information.                       | `show interfaces trunk`        | Helps identify VLAN trunk configuration issues.            |
| Interface Diagnostics    | Inspect detailed interface statistics, errors, and operational status.      | `show interfaces`              | Supports interface and performance troubleshooting.        |
| Configuration Inspection | Review the active device configuration.                                     | `show running-config`          | Identifies configuration errors and unexpected settings.   |
| Event Logging            | Inspect device-generated operational messages.                              | `show logging`                 | Provides troubleshooting and incident evidence.            |
| Secure Administration    | Access network devices remotely through encrypted management sessions.      | `ssh -l admin 10.10.10.1`      | Supports secure remote network administration.             |
| Configuration Validation | Compare operational results against intended network behavior.              | `show` and diagnostic commands | Confirms corrective actions and expected functionality.    |

## 4. Linux: System & Log Analysis

| Technical Capability        | Engineering Function                                           | Example Command                   | Key Benefit                                                             |
| --------------------------- | -------------------------------------------------------------- | --------------------------------- | ----------------------------------------------------------------------- |
| System Log Inspection       | Examine system-generated operational and diagnostic messages.  | `sudo tail -f /var/log/syslog`    | Supports system and service troubleshooting where this log file exists. |
| Log Searching               | Filter log files for errors, warnings, or relevant events.     | `grep -i "error" /var/log/syslog` | Accelerates identification of relevant log entries.                     |
| System Journal Analysis     | Review systemd journal entries and service events.             | `journalctl -xe`                  | Provides centralized system and service diagnostic information.         |
| IP Address Verification     | Inspect network interfaces and assigned IP addresses.          | `ip addr`                         | Identifies interface and addressing problems.                           |
| Routing Verification        | Display the Linux routing table.                               | `ip route`                        | Supports default gateway and routing diagnostics.                       |
| Socket and Port Inspection  | Examine active listening ports and network sockets.            | `ss -tlnp`                        | Helps identify active services and network listeners.                   |
| Connectivity Testing        | Test reachability to network destinations.                     | `ping 10.10.10.1`                 | Validates basic network connectivity.                                   |
| DNS Resolution Testing      | Query DNS records and verify hostname resolution.              | `nslookup example.com`            | Identifies DNS resolution problems.                                     |
| Service Health Verification | Inspect the operational state of a system service.             | `systemctl status ssh`            | Supports service availability troubleshooting.                          |
| Remote Administration       | Establish encrypted administrative sessions to remote systems. | `ssh admin@10.10.10.1`            | Enables secure device access and troubleshooting.                       |
| Automation Support          | Execute Python scripts and diagnostic utilities within Linux.  | `python3 diagnostics.py`          | Provides a flexible environment for network automation.                 |
