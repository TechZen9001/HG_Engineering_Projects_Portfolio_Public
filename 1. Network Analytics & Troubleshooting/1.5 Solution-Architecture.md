# Project 1 – Network Analytics & Troubleshooting

## 1.5 Solution Architecture Architecture Overview

Project 1 uses a centralized network analytics and troubleshooting architecture to collect operational data from routers, switches, firewalls, servers, and endpoints. Network monitoring platforms, packet analysis tools, Linux utilities, and Python automation work together to provide visibility into infrastructure health, support incident investigation, and generate actionable engineering reports.

![Project 1 — Solution Architecture](infographics/1.5%20Solution-Architecture.png)

| Executive Summary              | Description                                                                                                                                                                                                      |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Architecture Overview          | Project 1 uses a centralized network monitoring, analytics, and troubleshooting architecture to collect, analyze, and correlate operational data from routers, switches, firewalls, servers, and endpoints.      |
| Architecture Objective         | Improve network visibility, accelerate incident detection and resolution, and support data-driven engineering decisions through centralized monitoring, automated diagnostics, and standardized troubleshooting. |
| Architecture Design            | Network devices and services communicate operational information through a dedicated management network using Syslog, SNMP, network telemetry, and secure management connections.                                |
| Engineering Approach           | Collect → Analyze → Monitor → Alert → Troubleshoot → Resolve.                                                                                                                                                    |
| Core Technologies              | Cisco IOS, Linux, Python, Wireshark, SNMP, Syslog, SSH, CLI, PRTG, SolarWinds, Splunk, and Grafana.                                                                                                              |
| Architecture Value Proposition | Transform raw network data into actionable engineering insights, automated alerts, performance reports, validated corrective actions, and repeatable troubleshooting documentation.                              |
| Operational Objective          | Establish a centralized, scalable, and repeatable architecture supporting greater visibility, faster resolution, improved reliability, and stronger network operations.                                          |
