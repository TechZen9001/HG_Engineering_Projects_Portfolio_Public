# Project 6. Manufacturing IT / OT Cyber-Physical Network: Secure, Segmented, & Resilient

## 6.9 Project Outcomes Executive Results Dashboard

Project 6 demonstrates the successful design, implementation, configuration, troubleshooting, and validation of a secure, segmented, and resilient manufacturing IT/OT network using Cisco networking technologies. The Cisco Modeling Labs (CML) implementation integrates VLAN segmentation, IEEE 802.1Q trunking, controlled inter-VLAN routing, Access Control Lists (ACLs), Network Address Translation (NAT), Dynamic Host Configuration Protocol (DHCP), Rapid PVST+ redundancy, Network Time Protocol (NTP), and centralized Syslog monitoring. The project successfully validated all seven functional requirements, demonstrating practical enterprise network engineering, cybersecurity, infrastructure services, operational resilience, and technical documentation capabilities.
