# Project 6. Manufacturing IT / OT Cyber-Physical Network: Secure, Segmented, & Resilient

## 6.7 Tools Used

Project 6 integrates Cisco networking technologies, network simulation platforms, diagnostic utilities, infrastructure services, and technical documentation tools to design, configure, troubleshoot, and validate a secure manufacturing IT/OT network. The solution uses Cisco IOS, Cisco Modeling Labs (CML), VLANs, IEEE 802.1Q trunking, Access Control Lists (ACLs), Network Address Translation (NAT), Dynamic Host Configuration Protocol (DHCP), Rapid Per-VLAN Spanning Tree Plus (Rapid PVST+), Network Time Protocol (NTP), and Syslog. Supporting technologies include Python for potential automation, Wireshark for packet analysis, terminal and CLI utilities for device administration, and Git/GitLab for version control and documentation management.

![Project 6 — Tools Used](infographics/6.7%20Tools-Used.png)

Engineering Approach: Design → Configure → Secure → Troubleshoot → Validate → Document.
