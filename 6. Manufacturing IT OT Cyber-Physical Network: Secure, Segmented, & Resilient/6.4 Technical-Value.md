# Project 6. Manufacturing IT / OT Cyber-Physical Network: Secure, Segmented, & Resilient

## 6.4 Technical Value

Project 6 demonstrates practical engineering capabilities across enterprise network architecture, IT/OT segmentation, cybersecurity, infrastructure services, Layer 2 redundancy, troubleshooting, operational validation, and technical documentation. The solution integrates Cisco IOS, Cisco Modeling Labs (CML), VLANs, IEEE 802.1Q trunking, router-on-a-stick inter-VLAN routing, Access Control Lists (ACLs), Network Address Translation (NAT), Dynamic Host Configuration Protocol (DHCP), Rapid Per-VLAN Spanning Tree Plus (Rapid PVST+), Syslog, and Network Time Protocol (NTP). The project demonstrates how security by design, standardized network configurations, resilient connectivity, and evidence-based validation can support reliable manufacturing network operations.
