# Project 6. Manufacturing IT / OT Cyber-Physical Network: Secure, Segmented, & Resilient

## 6.2 Executive Overview

An enterprise manufacturing network engineering solution designed to provide secure IT/OT network segmentation, controlled access, resilient connectivity, centralized monitoring, and reliable business operations. The project demonstrates the design, implementation, configuration, troubleshooting, and validation of a segmented manufacturing network using Cisco networking technologies. The solution integrates Virtual Local Area Networks (VLANs), IEEE 802.1Q trunking, inter-VLAN routing, Access Control Lists (ACLs), Network Address Translation (NAT), Dynamic Host Configuration Protocol (DHCP), Rapid Spanning Tree Protocol (RSTP), Network Time Protocol (NTP), and Syslog. The objective is to establish a secure, reliable, and scalable manufacturing network that protects operational technology (OT) resources, supports business continuity, and minimizes disruptions to production.
