# Project 6. Manufacturing IT / OT Cyber-Physical Network: Secure, Segmented, & Resilient

## 6.8 Simplified Implementation

Project 6 follows a structured manufacturing network engineering lifecycle to design, build, configure, secure, monitor, test, validate, and document a segmented Cisco IT/OT network. The implementation uses Cisco Modeling Labs (CML) to deploy a five-node core topology with an additional guest testing endpoint. It integrates VLAN segmentation, IEEE 802.1Q trunking, router-on-a-stick routing, ACL enforcement, NAT, DHCP, Rapid PVST+, NTP, and Syslog. The project demonstrates a repeatable implementation methodology that combines secure network design, resilient infrastructure, controlled access, centralized monitoring, systematic troubleshooting, and evidence-based validation.

![Project 6 — Simplified Implementation](infographics/6.8%20Simplified-Implementation.png)

Implementation Workflow: Build Lab Topology → Configure Switches → Configure Router → Implement Network Security → Configure Infrastructure Services → Test and Validate → Document and Verify Completion.

## 8. Implementation Methodology

Structured Manufacturing Network Engineering Lifecycle

The solution follows a repeatable engineering methodology that combines network architecture design, infrastructure configuration, security implementation, operational monitoring, troubleshooting, validation, and documentation.

Implementation Lifecycle: Design → Build → Configure → Secure → Monitor → Test → Validate → Document.
