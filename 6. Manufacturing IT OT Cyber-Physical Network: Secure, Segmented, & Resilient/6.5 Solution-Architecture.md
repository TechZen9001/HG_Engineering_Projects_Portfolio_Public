# Project 6. Manufacturing IT / OT Cyber-Physical Network: Secure, Segmented, & Resilient

## 6.5 Solution Architecture Architecture Overview

Project 6 implements a secure, segmented, and resilient manufacturing network using Cisco networking technologies. The architecture integrates an edge/perimeter router, two interconnected Layer 2 switches, corporate and guest endpoints, and a centralized services server. The solution uses VLAN segmentation, IEEE 802.1Q trunking, router-on-a-stick inter-VLAN routing, Access Control Lists (ACLs), Network Address Translation (NAT), Dynamic Host Configuration Protocol (DHCP), Rapid Per-VLAN Spanning Tree Plus (Rapid PVST+), Syslog, and Network Time Protocol (NTP). The architecture provides controlled communication between IT and OT network segments, redundant switching paths, centralized monitoring, and structured validation of security and network functionality.

Architecture Approach: Secure → Segment → Connect → Monitor → Validate → Maintain Resilience.
