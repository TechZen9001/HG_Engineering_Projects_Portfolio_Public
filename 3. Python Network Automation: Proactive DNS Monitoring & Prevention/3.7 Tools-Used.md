# Project 3 – Python Network Automation: Proactive DNS Monitoring & Prevention

## 3.7 Tools Used

Project 3 uses Python automation, DNS diagnostic technologies, Windows and Linux administration utilities, scheduled execution, monitoring dashboards, notification services, and version control to support proactive DNS monitoring and incident prevention.

![Project 3 — Tools Used](infographics/3.7%20Tools-Used.png)

| Executive Summary         | Description                                                                                                                                                                                                                                               |
| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project Purpose           | Integrate Python automation, DNS diagnostic technologies, Windows and Linux administration utilities, scheduled execution, monitoring dashboards, notification services, and version control to support proactive DNS monitoring and incident prevention. |
| Technical Objective       | Establish a reusable technology stack that continuously monitors DNS health, validates configurations, detects anomalies, coordinates approved remediation, and generates incident reports and notifications.                                             |
| Core Technology Stack     | Python, Linux, DNS, ICMP, Windows DNS, Active Directory, PowerShell, Bash, `nslookup`, `dig`, Windows Task Scheduler, Cron, SMTP, Slack, ServiceNow/Jira, CSV, JSON, Grafana, Git, and Markdown.                                                          |
| Technology Architecture   | A centralized Python automation engine integrates DNS utilities, Windows/Linux services, scheduled monitoring, structured data, notification platforms, ticketing systems, and version-controlled scripts.                                                |
| Engineering Approach      | Monitor → Process → Integrate → Record → Improve.                                                                                                                                                                                                         |
| Security Principles       | Authorized monitoring, approved DNS configurations, least-privilege administration, controlled remediation, credential protection, and operational logging.                                                                                               |
| Technical Value           | Demonstrates Python programming, DNS administration, network diagnostics, automation scheduling, system integration, incident management, structured reporting, and technical documentation.                                                              |
| Business Value            | Earlier incident detection, improved DNS reliability, stronger security, reduced administrative effort, and greater operational efficiency.                                                                                                               |
| Overall Value Proposition | The Right Tools. Working Together for a More Reliable, Secure Network.                                                                                                                                                                                    |
