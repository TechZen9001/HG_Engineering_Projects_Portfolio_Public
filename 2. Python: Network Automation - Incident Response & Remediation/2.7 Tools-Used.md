# Project 2 – Python: Network Automation – Incident Response & Remediation

## 2.7 Tools Used

Project 2 uses Python programming, secure network connectivity libraries, structured data processing, notification services, version control, and technical documentation tools to automate incident response and remediation.

| ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
