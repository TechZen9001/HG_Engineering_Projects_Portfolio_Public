# Project 4. Network Automation & Deployment: VLANs, Configurations, SSH Security, Ansible, Netmiko, & Python

## 4.7 Tools Used

Project 4 uses Python automation, secure SSH connectivity, Ansible configuration management, ExtremeXOS networking technologies, structured inventory files, GitLab version control, and technical documentation tools to automate network configuration and deployment.

![Project 4 — Tools Used](infographics/4.7%20Tools-Used.png)

| Executive Summary           | Description                                                                                                                                                                                                 |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Project Title               | Network Automation & Deployment: VLANs, Configurations, SSH Security, Ansible, Netmiko, & Python                                                                                                            |
| Project Purpose             | Integrate industry-standard network automation, configuration management, secure connectivity, version control, and documentation technologies to automate enterprise switch administration and deployment. |
| Primary Objective           | Establish a secure, standardized, repeatable, and scalable toolchain for managing ExtremeXOS switches through a centralized Linux automation controller.                                                    |
| Core Technology Stack       | Python, Netmiko, Ansible, Linux, ExtremeXOS, SSH, RSA Keys, YAML, JSON, Git, GitLab, CLI, Configuration Backups, and Markdown.                                                                              |
| Primary Automation Platform | Linux automation controller running Python, Netmiko, Ansible, and supporting network administration utilities.                                                                                              |
| Managed Infrastructure      | Four ExtremeXOS access switches connected through the N-CoreA-01 core switch.                                                                                                                               |
| Automation Capabilities     | Device discovery, VLAN configuration, SSH connectivity, configuration backups, administrative account management, deployment validation, and technical reporting.                                           |
| Security Architecture       | Encrypted SSH communication, RSA key-based authentication, controlled administrative access, and protected automation credentials.                                                                          |
| Configuration Management    | Ansible playbooks, YAML inventories, standardized device settings, and reusable deployment workflows.                                                                                                       |
| Version Control             | Git and GitLab maintain automation scripts, inventories, playbooks, configuration artifacts, and engineering documentation.                                                                                 |
| Engineering Approach        | Automate → Standardize → Secure → Deploy → Validate → Document.                                                                                                                                             |
| Expected Outcomes           | Faster deployments, consistent configurations, stronger security, reduced human error, improved operational visibility, and scalable network management.                                                    |
| Strategic Principle         | The Right Tools. A Stronger, More Automated Network.                                                                                                                                                        |
