
# Recruiter Resources: Project 4. Network Automation & Deployment – VLANs, Configurations, SSH Security, Ansible, Netmiko, & Python

Network Engineering • Cybersecurity • Python Automation • VLAN Deployment • SSH Security • Configuration Management • Infrastructure Validation

## Executive Overview

This directory provides a recruiter-focused summary of Project 4, highlighting practical network automation capabilities, secure ExtremeXOS switch administration, automated VLAN discovery and deployment, configuration backups, Ansible configuration management, Python scripting, technical evidence, relevant career opportunities, and architecture decisions.

The project demonstrates a centralized network automation framework using a Linux automation controller, Python, Netmiko, Ansible, SSH key-based authentication, and GitLab to securely manage four ExtremeXOS access switches supporting departmental network segmentation.

The resources complement the detailed technical documentation available in the main project directory.
