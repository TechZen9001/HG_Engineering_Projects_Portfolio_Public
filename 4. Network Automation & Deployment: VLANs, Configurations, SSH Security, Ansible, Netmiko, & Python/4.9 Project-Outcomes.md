# Project 4. Network Automation & Deployment: VLANs, Configurations, SSH Security, Ansible, Netmiko, & Python

## 4.9 Project Outcomes Executive Results Dashboard

Project 4 demonstrates a secure network automation and deployment framework using Python, Netmiko, Ansible, SSH key-based authentication, and GitLab to manage four ExtremeXOS access switches. The laboratory implementation demonstrated VLAN discovery and deployment, automated configuration backups, secure device access, Ansible-driven local administrator creation, and network configuration validation.
