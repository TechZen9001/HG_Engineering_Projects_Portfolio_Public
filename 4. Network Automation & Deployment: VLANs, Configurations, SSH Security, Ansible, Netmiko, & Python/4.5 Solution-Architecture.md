# Project 4. Network Automation & Deployment: VLANs, Configurations, SSH Security, Ansible, Netmiko, & Python

## 4.5 Solution Architecture

Project 4 uses a centralized Linux automation controller running Python, Netmiko, and Ansible to securely manage four ExtremeXOS access switches through the core network infrastructure. The controller uses SSH key-based authentication, device inventories, automation scripts, and Ansible playbooks to perform VLAN discovery, configuration deployment, configuration backups, administrative account management, and validation.
