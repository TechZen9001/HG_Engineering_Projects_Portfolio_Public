## Featured Project Overview

![Project 4 — Executive Overview](4.2%20Executive-Overview%20A.png)

**Project Objective:** Design and implement an enterprise network automation framework that standardizes switch configurations, automates Virtual Local Area Network (VLAN) deployment, establishes secure SSH key-based administration, backs up network configurations, and validates infrastructure changes using Python, Netmiko, and Ansible.

## Engineering Capabilities Demonstrated

1. **Python Network Automation:** Develop reusable Python scripts to automate switch configuration, VLAN deployment, configuration backups, operational validation, and infrastructure management.
2. **Netmiko Network Device Management:** Establish SSH connections with ExtremeXOS switches, execute CLI commands, retrieve configuration information, and automate administrative operations.
3. **Ansible Configuration Management:** Develop YAML-based inventories and playbooks to standardize network configurations, automate administrative tasks, and execute repeatable deployment workflows.
4. **VLAN Deployment and Network Segmentation:** Automate the creation, configuration, and verification of departmental VLANs for IT, Management, Accounting, and Users.
5. **Secure SSH Authentication:** Implement SSH key-based authentication, controlled administrative connectivity, and secure remote network device access.
6. **Automated Configuration Backups:** Retrieve and archive network device configurations to support change tracking, troubleshooting, recovery, and configuration preservation.
7. **Multi-Device Network Automation:** Centrally manage multiple ExtremeXOS switches using reusable Python scripts, Ansible inventories, and standardized playbooks.
8. **Network Discovery and Validation:** Automate device connectivity checks, VLAN discovery, configuration verification, and operational testing.
9. **Version Control and Change Management:** Maintain automation scripts, Ansible playbooks, inventory files, configurations, and documentation using Git and GitLab.
10. **Modular Architecture and Scalability:** Build reusable automation modules and structured deployment workflows that support additional switches, VLANs, and network environments.
11. **Network Troubleshooting:** Investigate SSH connectivity failures, configuration errors, YAML formatting problems, inventory issues, and unsuccessful automation tasks.
12. **Technical Documentation and Reporting:** Produce architecture diagrams, configuration records, deployment logs, validation results, troubleshooting documentation, and engineering evidence.
